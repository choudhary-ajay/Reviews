# Dynamic Feedback & Rating Application

A full-stack Feedback & Rating webpage built using React, Node.js, Express.js, and MongoDB.

Users can:
- Submit a rating and review
- Select a rating using interactive stars
- View submitted reviews
- See reviews dynamically fetched from the backend
- Store feedback permanently in MongoDB
